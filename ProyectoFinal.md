Parte 1. Fundamentos de programación

1. Algoritmo	  	

Definición: Un algoritmo es una serie de pasos para resolver un problema o solo para realizar una tarea. Como por ejemplo, una receta de comida, que tiene una serie de pasos para poder preparar la comida.

Referencia: El algoritmo: Qué es y por qué importa | SAS ES. (s. f.). SAS. https://www.sas.com/es_es/insights/analytics/algorithms.html

2. Programa
Definición: Conjunto de instrucciones hechas para que una computadora haga una tarea en específico, todo hecho con código de programación. Por ejemplo, Teams o Visual Studio Code.

Referencia: ¿Qué es un programa? | Lenovo México. (s. f.). https://www.lenovo.com/mx/es/glosario/programa/?orgRef=https%253A%252F%252Fwww.google.com%252F&srsltid=AfmBOorkX0wPcgy8ySM1A-JJ6yNrLrhQdR6IXk6OwL6ezCmoUnByAjpe
4. Código fuente
Definición: El código fuente es un conjunto de instrucciones escritas por un programador en un lenguaje de programación, como por ejemplo Python o JavaScript. A diferencia de otros códigos, como el número binario, que no puede entender una persona, el código fuente sí puede entenderlo.
Referencia: Código Fuente: ¿qué es? | Lenovo México. (s. f.). https://lenovo.com/mx/es/glosario/codigo-fuente/?srsltid=AfmBOorYZLID8l5NwZqp6mBxWZwtuyBP785bZy7--tESULiCjFN2Ujkq
5. Lenguaje de programación
Definición: Es un sistema formal de símbolos, donde encuentras palabras clave y otras reglas gramaticales para lograr que una persona escriba instrucciones a una computadora y así ejecutarlas. En otras palabras, es el idioma que usamos las personas para decirle a una computadora qué hacer paso a paso.
Referencia: Equipo editorial, Etecé. (2026, 9 junio). Lenguaje de programación - Qué es, tipos y ejemplos. Concepto. https://concepto.de/lenguaje-de-programacion/
6. Sintaxis
Definición: Son las reglas gramaticales que te dicen cómo se debe escribir correctamente un código en un lenguaje de programación. Es lo mismo que la gramática en un idioma humano, así como en español no puedes poner mal el orden de las frases.
Referencia: Giani, C. (2025, 2 agosto). Sintaxis - Concepto, elementos, funciones y ejemplos. Concepto. https://concepto.de/sintaxis/
7. Variable
Definición: Un espacio en la memoria de tu computadora usado para guardar y almacenar datos que pueden cambiar (o variar, por eso se llaman variables) mientras el programa está ejecutándose. Le pones un nombre para poder referirte a ese dato.
Referencia: Equipo editorial, Etecé. (2026a, junio 8). Variable - Qué es, tipos y para qué sirven. Concepto. https://concepto.de/variable/
8. Constante
Definición: Es como una variable, pero con una diferencia clave: el valor o el dato que está acá no puede cambiar después de ser asignado.
Referencia: Palomares, K. (2025, 14 abril). ¿Qué es una Constante en Programación? - ¡Ejemplos fáciles! Cuarzo.dev. https://newsletter.cuarzo.dev/p/que-es-una-constante-en-programacion
9. Tipo de dato
Definición: Un tipo de dato es qué clase de información va a tener tu variable y qué operaciones puedes hacer con ella. Le dice a la computadora cómo interpretar y almacenar ese valor en la memoria.
Tipos de datos primitivos (los más básicos):
Tipo	Descripción	Ejemplo
Entero (int)	Números sin decimales	25, -10, 0
Flotante (float / double)	Números con decimales	3.14, 1.65, -0.5
Texto (string / str)	Cadenas de caracteres	"Hola", "Ana"
Booleano (bool)	Solo dos valores: verdadero o falso	True, False
Carácter (char)	Un solo carácter (en algunos lenguajes)	'a', 'Z'
Referencia: Senestrari, L. (2026, 8 abril). Tipos de datos en programación: lo que tenés que saber. Onmex. https://onmex.mx/tecnologia-y-desarrollo/cuales-son-los-tipos-de-datos-en-programacion/
10. Operador
Definición: Es un símbolo que le indica a la computadora que realice una operación específica sobre uno o más valores, como sumar, comparar o asignar un valor. Por ejemplo: división (/), multiplicación (*), resta (-) y suma (+).
Referencia: Formación, A. (2025, 4 noviembre). ¿Qué es un operador en programación? https://www.adrformacion.com/knowledge/programacion/_que_es_un_operador_en_programacion_.html
11. Expresión
Definición: Una expresión es cualquier combinación de valores, variables y operadores que, al evaluarse, produce un resultado (un valor). Es decir, si los operadores son las "acciones" y las variables son los "datos", una expresión es la combinación de ambos que la computadora puede resolver para obtener un valor.
Referencia: Mozilla. (s. f.). Expresiones y operadores. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Operators
12. Condicional
Definición: Es una estructura que nos deja elegir entre ejecutar una acción u otra según se cumpla o no una condición, como por ejemplo el IF o el SI en pseudocódigo.
Referencia: Mozilla. (s. f.). Control de flujo y manejo de errores. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Guide/Control_de_flujo_y_manejo_de_errores
13. Bucle
Definición: Estructura de control que repite un conjunto de instrucciones mientras se cumpla una condición.
Referencia: Mozilla. (s. f.). Bucles e iteración. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Guide/Loops_and_iteration
14. Función
Definición: Bloque de código reutilizable que agrupa instrucciones para realizar una tarea específica. Le pones un nombre y, cada vez que la necesitas, simplemente la "llamas".
Referencia: Mozilla. (s. f.). Funciones. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Referencia/Funciones
15. Parámetro
Definición: Es el nombre que le das a la información que una función espera recibir. Piénsalo como un espacio vacío que dejas listo para cuando llegue el dato real.
Referencia: Mozilla. (s. f.). Funciones. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Referencia/Funciones
16. Argumento
Definición: Es el valor real que le das a la función cuando la usas. La diferencia con el parámetro es sutil: el parámetro es el "molde" y el argumento es lo que realmente metes ahí cuando la llamas.
Referencia: Mozilla. (s. f.). El objeto arguments. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Reference/Functions/arguments
17. Retorno
Definición: Es lo que la función te "devuelve" después de hacer su trabajo, usando la palabra return. Si no le pones un return, la función simplemente no te da nada de vuelta.
Referencia: Mozilla. (s. f.). Funciones. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Referencia/Funciones
18. Arreglo
Definición: Es básicamente una lista donde guardas varios valores juntos, en orden, bajo un mismo nombre. En vez de crear 10 variables para 10 números, guardas los 10 en un solo arreglo.
Referencia: Mozilla. (s. f.). Colecciones indexadas. MDN Web Docs. https://developer.mozilla.org/es/docs/Web/JavaScript/Guide/Indexed_collections
19. Objeto
Definición: Es una forma de agrupar datos relacionados en un solo lugar. Por ejemplo, en vez de tener variables sueltas como nombre, edad y correo, las metes todas dentro de un objeto llamado persona.
Referencia: Mozilla. (s. f.). Working with objects. MDN Web Docs. https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Working_with_Objects
20. Método
Definición: Es simplemente una función, pero que vive dentro de un objeto. Por eso puede usar directamente los datos de ese objeto sin que tengas que pasárselos.
Referencia: Mozilla. (s. f.). Working with objects. MDN Web Docs. https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Working_with_Objects

21. Evento
Definición: Es algo que pasa mientras el usuario usa el programa (un clic, apretar una tecla, mover el mouse) y que el código puede "escuchar" para reaccionar cuando ocurre.
Referencia: Mozilla. (s. f.). Introduction to events. MDN Web Docs. https://developer.mozilla.org/docs/Learn_web_development/Core/Scripting/Events

Parte 2. Comandos básicos de Linux

21. Pwd
Definición: Este comando se usa en Linux para ver la ruta del directorio en el que estás en ese momento.
Ejemplo: pwd → muestra algo como /home/usuario/documentos

22. Ls
Definición: Este comando se usa para ver el contenido de un directorio.
Ejemplo: ls → muestra los archivos y carpetas que hay dentro del directorio actual

23. Cd
Definición: cd es de los comandos más usados, según tengo entendido, porque este se usa para moverte entre archivos y entre otros directorios.
Ejemplo: cd documentos → te mueve dentro de la carpeta "documentos"

24. Mkdir
Definición: Este es para crear un nuevo directorio estando adentro de otro directorio.
Ejemplo: mkdir tareas → crea una carpeta nueva llamada "tareas"

25. Touch
Definición: Este comando crea un nuevo archivo en blanco por medio de tu línea de comandos de Linux. Se puede usar para asignarle un tipo de dato; por ejemplo, para hacer un documento.html lo crearías con touch.
Ejemplo: touch index.html → crea un archivo vacío llamado "index.html"

26. Cp
Definición: Este comando es usado para copiar archivos del directorio en el que estás a uno diferente.
Ejemplo: cp tarea.txt respaldo/ → copia el archivo "tarea.txt" a la carpeta "respaldo"

27. Mv
Definición: Este es para mover archivos o para cambiar nombres de archivos.
Ejemplo: mv tarea.txt tareas/ → mueve el archivo "tarea.txt" a la carpeta "tareas"
Ejemplo 2: mv tarea.txt tarea_final.txt → le cambia el nombre a "tarea_final.txt"

28. Rm
Definición: Comando para eliminar archivos. Si se usa con la opción -r (recursivo), también elimina directorios junto con todo el contenido que hay en ellos. Para eliminar únicamente un directorio vacío existe la alternativa rmdir.
Ejemplo: rm tarea.txt → elimina el archivo "tarea.txt"
Ejemplo 2: rm -r tareas → elimina la carpeta "tareas" junto con todo lo que hay adentro

29. Cat
Definición: Este comando se puede usar para listar contenido en un archivo desde su salida estándar. También puede concatenar contenido.
Ejemplo: cat tarea.txt → muestra en pantalla todo el contenido del archivo "tarea.txt"

30. Less
Definición: Este comando se usa para ver el contenido de un archivo pantalla por pantalla, sin que se salga todo de golpe como con cat. Es útil para archivos grandes porque puedes subir y bajar y buscar palabras dentro del archivo.
Ejemplo: less registro.txt → abre el archivo "registro.txt" para irlo revisando poco a poco

31. Head
Definición: Este comando muestra las primeras líneas de un archivo; por defecto son las primeras 10. Sirve para echar un vistazo rápido sin tener que abrir todo el archivo.
Ejemplo: head datos.csv → muestra las primeras 10 líneas del archivo "datos.csv"

32. Tail
Definición: Es lo contrario de head, muestra las últimas líneas de un archivo. Se usa mucho para ver los logs más recientes de un archivo que se sigue actualizando.
Ejemplo: tail error.log → muestra las últimas 10 líneas del archivo "error.log"
33. Clear
Definición: Este comando limpia la pantalla de la terminal, o sea, borra todo lo que se ha escrito antes para dejarla limpia otra vez.
Ejemplo: clear → deja la terminal en blanco, lista para seguir trabajando

34. Echo
Definición: Este comando se usa para mostrar un texto o un mensaje en la terminal. También sirve para meter texto dentro de un archivo cuando lo combinas con otros comandos.
Ejemplo: echo "Hola mundo" → muestra en pantalla el texto "Hola mundo"
Ejemplo 2: echo "Hola" > saludo.txt → guarda el texto "Hola" dentro del archivo "saludo.txt"

35. Man
Definición: Es el manual de los comandos; o sea, si no te acuerdas cómo se usa algún comando o qué opciones tiene, con man puedes ver toda la información de ese comando.
Ejemplo: man ls → muestra el manual completo del comando "ls"
36. Whoami
Definición: Este comando te dice el nombre del usuario con el que estás conectado en ese momento en la terminal.
Ejemplo: whoami → muestra algo como "usuario"

37. Date
Definición: Este comando muestra la fecha y la hora actual del sistema.
Ejemplo: date → muestra algo como "jue 24 sep 2026 10:32:00"
38. Grep
Definición: Este comando se usa para buscar una palabra o un patrón de texto dentro de un archivo o dentro de la salida de otro comando.
Ejemplo: grep "error" registro.txt → muestra solo las líneas del archivo "registro.txt" que contienen la palabra "error"

39. Find
Definición: Este comando sirve para buscar archivos o directorios dentro del sistema, ya sea por nombre, por tipo o por otras características.
Ejemplo: find . -name "tarea.txt" → busca un archivo llamado "tarea.txt" dentro de la carpeta actual y sus subcarpetas
40. Sudo
Definición: Este comando se usa para ejecutar otro comando con permisos de administrador; o sea, con permisos más altos de los que tiene tu usuario normal.
Ejemplo: sudo apt update → ejecuta el comando "apt update" con permisos de administrador
